# Play Cursor

A FastAPI-based application for exploring and learning, now with random fact haiku generation and a made-up but believable fact using Ollama's Mistral model.

## Ollama Model Recommendation

For text generation, use the `mistral` model with Ollama for best performance on 8GB RAM (such as in Docker or cloud environments). You can also try `phi3` or other small models if available. If you have more memory, you may use larger models like `llama3`.

To pull the model:
```bash
ollama pull mistral
```

Make sure Ollama is running locally (default API: `http://localhost:11434`).

> **Note:** You can change the model by editing the `OLLAMA_MODEL` variable in `play_cursor/main.py`, or by passing the `--model` option to the CLI.

## Local Development

### Prerequisites
- Python 3.10.7 (using pyenv)
- Poetry (Python package manager)
- Ollama running with the `mistral` model

### Setting up the Development Environment

1. Install dependencies using Poetry:
```bash
poetry install
```

2. Activate the virtual environment:
```bash
poetry shell
```

3. Run the application:
```bash
uvicorn play_cursor.main:app --reload
```

The application will be available at `http://localhost:8000`

### Gradio UI Features
- Enter your name to get a greeting.
- Enter a topic to get:
  - A random fact about that topic as a haiku, generated by Ollama's Mistral model.
  - A random made-up but believable fact about that topic, generated by Ollama's Mistral model.
- Both the haiku and the made-up fact will be displayed side by side in the UI.
- The Gradio UI is available at: `http://localhost:8000/ui`

### API Documentation
- Swagger UI: `http://localhost:8000/docs`

### PWA Support
- The app serves a manifest at: `http://localhost:8000/manifest.json`

## Docker Deployment

### Prerequisites
- Docker and Docker Compose installed
- Ollama running on your host machine at `http://localhost:11434` (default)

### Using Docker Compose (Recommended)

1. Build and start the container (foreground):
```bash
play-cursor run-compose --model mistral
```

2. To run in detached mode (background):
```bash
play-cursor run-compose --model mistral --detach
```

3. To stop the container:
```bash
docker-compose down
```

### Using Docker Directly

1. Build and run the Docker container (foreground):
```bash
play-cursor run-docker --model mistral
```

2. To run in detached mode (background):
```bash
play-cursor run-docker --model mistral --detach
```

The application will be available at `http://localhost:8000` and the Gradio UI at `http://localhost:8000/ui`.

> **Note:** The app expects Ollama to be running on the host at `http://localhost:11434`. If running Docker on Mac, this should work by default. If you run Ollama in a container, ensure the network is configured correctly (e.g., use `host.docker.internal` for the Ollama URL inside the container on Mac/Windows).

## Command Line Usage

After installing dependencies (or building the Docker image), you can use the CLI:

- Run locally:
  ```bash
  play-cursor run-local --model mistral
  ```

- Run with Docker:
  ```bash
  play-cursor run-docker --model mistral
  # or in detached mode
  play-cursor run-docker --model mistral --detach
  ```

- Run with Docker Compose:
  ```bash
  play-cursor run-compose --model mistral
  # or in detached mode
  play-cursor run-compose --model mistral --detach
  ```
